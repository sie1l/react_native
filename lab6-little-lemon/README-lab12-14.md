# Лабораторні роботи №12 і №14 (Little Lemon)

## Запуск

```bash
npm install
npx tsc --noEmit
npx expo start
```

Відкрити в Expo Go на Android/iOS (SQLite у веб-версії не потрібен). Шлях: Login → Welcome →
кнопки **«Налаштування»** і **«Клієнти»**. Меню з API (№11) відкривається кнопкою «Меню» в заголовку.

## №12. AsyncStorage

- `storage/preferences.ts` — тип, `defaults`, ключ `@little-lemon/preferences/v1`, `parsePreferences`
  (перевірка типів), `readPreferences` / `writePreferences` / `removePreferences`.
- `screens/PreferencesScreen.tsx` — 4 перемикачі, явне «Зберегти», «Повторити читання», «Скинути».
- Самостійні: 4-й параметр «Показувати підказки меню»; резюме вибору зі state; екран не робить мережевих запитів
  (меню завантажується лише на власному екрані `RemoteMenu`, тож відкривання/закривання Preferences його не чіпає).
- Формат: запис `{version: 2, data: {...}}`. Старий запис `version: 1` (3 параметри) читається, а новий параметр
  отримує значення за замовчуванням `false`.

### Таблиця перевірок

| Дія | Очікується | Результат |
| --- | --- | --- |
| Перший запуск без ключа | усі вимкнені, форма доступна після читання | _заповнити після запуску_ |
| 1-й і 3-й → Зберегти → повний перезапуск | true, false, true | _…_ |
| Змінити без збереження → перезапуск | старі збережені значення | _…_ |
| Скинути → перезапуск | defaults, інші екрани/дані цілі | _…_ |
| Вимкнути мережу | налаштування працюють | _…_ |
| Пошкоджений ключ (`'{broken'`) | видима помилка, доступні «Повторити» і «Скинути» | _…_ |

## №14. expo-sqlite

- `storage/customers.ts` — відкриття бази один раз (спільна Promise), `user_version`, схема в транзакції,
  `listCustomers` / `addCustomer` / `renameCustomer` / `deleteCustomer` (параметри `?`, `WHERE id = ?`, перевірка `changes`).
- `screens/CustomersScreen.tsx` — форма додавання/редагування, список `FlatList`, підтвердження видалення з ім'ям та ID,
  блокування кнопок (`busy` + `ref`), прапорець `committed` (запис є, а перечитування впало).
- Самостійні: пошук за іменем (відфільтрований масив зі state), лічильники «усього / знайдено»,
  скасування редагування не торкається бази.
