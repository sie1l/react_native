# Лабораторна робота №8. Pressable, зображення і хуки

Продовження застосунку Little Lemon (матеріали лабораторних №6–7).

## Що реалізовано

- Форма входу з двома керованими полями (`email`, `password`).
- Кнопка на `Pressable` з візуальним станом `pressed` і `accessibilityRole="button"`.
- Локальна перевірка email і пароля з повідомленням про помилку.
- Після успішної перевірки відкривається екран привітання; пароль очищується й не передається далі.
- Повернення до форми через `onExit`.
- Локальний логотип `assets/images/logo.png` з `resizeMode="contain"`.
- Автоматична світла/темна тема через `useColorScheme()` і палітри `theme/palette.ts`.
- Кольори застосовані до фону, шапки, підвалу, тексту, полів, підказок, рамок, кнопок і помилок.
- Адаптивне компонування блоку з логотипом на екрані привітання (`useWindowDimensions`, поріг 600).

## Запуск

```bash
cd lab6-little-lemon
npm install
npx expo start
```

Далі відкрийте застосунок в Expo Go або емуляторі Android/iOS.

## Перевірка типів

```bash
npx tsc --noEmit
```

## Перевірка роботи

1. Натиснути «Увійти (демо)» з порожніми полями — з'являється повідомлення про email.
2. Ввести `student` і будь-який пароль — повідомлення про формат email.
3. Ввести `student@example.com`, пароль залишити порожнім — повідомлення про пароль.
4. Ввести `student@example.com` і непорожній пароль — відкривається привітання з email без крайніх пробілів.
5. Натиснути «Повернутися до форми» — форма знову порожня.
6. Змінити системну тему на телефоні — кольори обох екранів оновлюються, введені дані не скидаються.
7. Перевірити, що логотип не обрізаний і не розтягнутий.
